How to get a key

  • Sign up at openrouter.ai.
  • Add prepaid credit under Settings → Credits.
  • Go to openrouter.ai/keys and click Create Key.
  • Copy the key (it starts with sk-or-v1-) and paste it above.
  • Press Save Settings.

Your key stays in this browser's local storage and is sent only to the article generator backend for the request you asked for. It is never stored on the server and never shared with anyone else. Anyone with access to this device can read it — revoke it at openrouter.ai/keys if you use a shared computer.
